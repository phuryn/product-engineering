# ui-design: receipts

Each heading is a rule from `SKILL.md`, with the case that taught it.

## Load this skill for the whole of a product's look.

- `Undated`: Before it, the method lived in one file, the choice of skills in another, the screen rules in the test docs and the review in a skill of its own, and a product that read only some of them repeated mistakes the others had already written down.

## Replace `design` with `ui-design` in product agent instructions.

- `2026-11-07`, formerly `design`, renamed: in a content repository without `app-stack` enabled, `Skill("design")` reached Claude Code's own `/design` command, which only the user can start, and its refusal read as if this skill were user-only.

- `2026-11-03`, an evals product's artifact imitated its kit, invented borderless buttons and misaligned chips; its builder had read this page but never the method.

- `2026-11-02` to `2026-11-03`, the pack released three versions.

- `2026-11-03`, codex-cli 0.166.0: a headless `codex exec` loaded it once the pack was installed.

## Map the user's jobs before drawing any screen, a builder's included.

- `2026-11-03`, an evals product: its screens mirrored its tables and its method's vocabulary, and someone who knew the tool it replaced couldn't follow the process. The owner: "super technical, like a database".

## Run every visual check before the owner's click-through.

- `2026-11-03`, an evals product: the design stage was skipped by a recorded decision, nothing brought it back, no screen was rendered and checked, and the owner's click-through found five layout bugs, most of them rules the method already had.

## Run the scored Impeccable-style audit before the owner's click-through at the first screens and whenever the kit changes.

- `2026-11-05`, an evals product passed the walkthrough and rendered pass but ran neither critique nor audit nor owner look review: control borders measured 1.61:1 against the method's 3:1, and the loudest colour on every healthy screen said *press* three or four times.

- `2026-11-04`, an evals product: a fresh `claude -p` session using this recipe found in about 20 minutes that no screen said how often each failure happened, a gap three review rounds missed.
