# retro: receipts

Each heading is a rule from `SKILL.md`, with the case that taught it.

## Hold the fix in code wherever code can hold it.

- `2026-06-15`, an agent-run repository: a two-line bug in a notification script was answered with a written convention; five weeks later the same bug killed a scheduled job for five days. Writing it down felt like fixing it.

## Don't gate what the owner wouldn't want to click for.

- `2026-10-12`: a one-way-door hook that also gated routine commands fired on a heredoc that merely mentioned one, the owner said "I don't want those questions", and it was narrowed the same day.
